# NC Frozen Vision and Roadmap

## Core Position
Nautical Compass is a compliance-first, AI-powered legal, workforce, business-formation, and advancement infrastructure platform.

NC is not just an app. It is a rail system.

## Operator Rail
NC helps users move:

Worker -> Contractor -> Structured Business -> Operator -> Prime / Coordinator

Core tools:
- profile intake
- business-readiness checklist
- bank-readiness checklist
- document vault
- filing sequence guidance
- renewal reminders
- annual filing reviews
- UCC renewal reminders before expiration
- compliance next-step routing

## Case Dock Legal Rail
Primary legal workflow:

Case Dock -> Matter State -> Timeline -> Evidence -> Standing -> Capacity -> Rights -> Remedies -> Packet -> Complaint Draft

Must remain:
- evidence-first
- doctrine-based
- capacity-aware
- jurisdiction-aware
- user-safe
- not legal advice

## Agent Build Doctrine
Do not activate broad autonomy until one workflow works end-to-end.

Controlled order:
Captain -> Builder -> Validator

Agents are tools, not uncontrolled workers.

## AXIOM Lessons Learned
Before building for outside parties:
- define scope
- define deliverables
- define milestone payments
- define acceptance criteria
- protect NC reusable IP
- separate client-specific work from NC infrastructure
- avoid pricing precedent that undervalues future work

## IP Protection Doctrine
NC retains ownership of:
- backend architecture
- orchestration methods
- prompts
- AI workflows
- routing concepts
- deployment patterns
- auth/billing/admin systems
- reusable modules
- platform logic

External work should be licensed, not transferred, unless explicitly agreed.

## AVPT Reputation Doctrine

Use objective evidence:
- attendance
- completion
- cancellations
- rehire behavior
- payment history
- check-in/out records
- incident reports
- client reliability
- worker reliability
- safety conduct

Build:
- Worker Confidence Score
- Client Confidence Score
- Rehire Signal
- Payment Reliability Signal
