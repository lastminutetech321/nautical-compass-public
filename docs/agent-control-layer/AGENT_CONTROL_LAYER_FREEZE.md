## Build Priority

## Core Agent Command Structure

### Captain Agent
Mission control. Assigns work, reviews outputs, coordinates agents, and blocks unsafe changes.

### Builder Agent
Creates code, schemas, routes, UI layers, and migrations only when assigned by Captain.

### Validator Agent
Runs tests, audits, doctrine checks, schema checks, and architecture compliance checks.

### Deployment Agent
Handles git, staging, release checks, rollback points, and production deployment.

### Monitor Agent
Watches uptime, logs, route failures, disk, memory, SSH, Tailscale, Docker, app health, and failed jobs.

### Recovery Agent
Restores checkpoints, rolls back deployments, restarts safe services, and escalates destructive actions.

## Offer Architecture Agent Rule
Hormozi-style offer engineering belongs only in the Growth Layer.

It may optimize:
- offer structure
- pricing ladders
- subscription packaging
- upgrade paths
- landing pages
- conversion copy
- value articulation
- retention strategy

It may not alter:
- facts
- evidence
- legal conclusions
- standing analysis
- capacity analysis
- timelines
- witness statements
- remedies
- user rights
- distress-safe rules

Legal Engine = Truth Layer.
Offer Architecture Agent = Packaging Layer.
